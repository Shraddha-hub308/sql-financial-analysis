
# SQL Financial Analysis

This project contains SQL queries for analyzing financial data, including:
- Expense records and category-wise spending analysis
- Client transaction patterns and top clients by volume
- Monthly revenue trends and reporting insights

## Skills Demonstrated
- SQL SELECT, WHERE, GROUP BY, ORDER BY
- JOIN operations across multiple tables
- Aggregate functions (SUM, COUNT)
- Date-based analysis and trend identification

## Dataset
Sample financial transactions dataset used for practice and analysis.
